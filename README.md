# TaxFloridaBillionaires.com

Let's make Spending The Florida Billionaire Tax Game using these data sources: https://billionairereporter.com/list-floridas-billionaires/ 
https://stacker.com/stories/florida/richest-billionaires-florida that focuses on the user experience in deciding how they could spend a Florida Billionaire tax. This game is for educational information purposes and should be as accurate as possible in terms of numbers and relation of visuals to numbers. The undertone of the site should we need to tax Florida billionaires and that Mark Zuckerberg has also become latest California billionaire to relocate to Florida amid tax concerns. The goal of the game is to show how much we could tax and where it could be invested like early childhood education (see New York and New Mexico recent investments), Healthcare, supporting federal cuts in Florida using detail from this article: https://www.wusf.org/health-news-florida/2025-04-08/medicaid-cuts-could-put-3-billion-hole-florida-economy-study Describe other game mechanics that may be a better approach before developing anything
